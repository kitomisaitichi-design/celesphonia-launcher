# Imprint-menu translation and fitting — launcher 1.0.31

The complaint reproduces in the native Three-in-One Ver1.061 imprint menu: weapon131 grants skills36,41,135,138, but the left panel contains Chinese fragments and clips English titles. TMMagicSlot's Window_MagicExplain.drawDescription splits the original description by character before calling drawText. Whole reviewed descriptions already exist in the English bank, but those fragments do not match their source keys.

The display adapter attaches only to the private Window_MagicExplain prototype when that native window is constructed. It translates complete native skill names/descriptions before measuring, wraps English on word boundaries, fits titles, preserves native skill colors and scrolls dense content in the existing panel. Conventional equipment/stat abbreviations are reused only when the complete panel overflows. Native data, item traits, skill IDs, conditions, costs, formulas and effects are never rewritten.

The related inventory contains80 imprint weapons /130 granted skills in Ver1.061, and82 weapons /120 skills in Maple1.7.2. All complete description fields already have English targets; this is a renderer-routing fix, not130 newly translated skills. A source/target numeric review found four inherited target errors: `[被动]ATK+10%`, `[被动]ATK+15%`, `[被动]最大HP+10%`, `[被动]最大HP+15%`. Their English values now match the original percentages in every existing compatible pack containing those exact keys. The correction mapping is recorded in Tests/ImprintTranslationCorrections.json. No broad substring substitution is used. A1.5x healing description expressed as +50% is semantically equivalent and retained.

Native before/after fixtures use the original menu/plugin via callMagicEquip in the real engines, English enabled and optional controls disabled. A private three-imprint/four-slot state reproduces the supplied selection. Full native captures are retained locally; the bundled illustrations are native-size detail captures of the affected description window, avoiding unrelated portraits and empty menu space. PNG encoding is lossless and verified by decoded RGBA hashes. Fixtures exercise every imprint, word/title bounds, dense scrolling, empty selection, repeated rendering and the native reset/inventory return. Renderer checks compare original database and prepared actor/inventory/variable/switch state; these are private UI checks, not a full save progression or gameplay playthrough.

Source inventories, native reports, exact hashes, authoring/install/package proofs and failure notes are retained in the coordination workspace. The first after fixture's wheel check attempted to assign getter-only TouchInput.x/y; corrected only the fixture to use the engine's backing coordinates. The native content checks preceding it passed; the failed report is retained and is not counted as a pass. No product exception was suppressed.

The package continues to ship only the runtime allowlist. Notes and these native images are embedded in the launcher for offline viewing. Existing source verification, save paths, profile settings, game versions and update/apply/restore boundaries are retained. Dictionary catalogs and native source inventories are unchanged. This is a partial English overlay, and the separate unconfirmed crash investigation is not presented as fixed by this release.
