DETECTION
Searches include the launcher folder/subfolders, registered game folders and their
parents, install location, native Documents/Desktop/Downloads/Telegram Desktop,
and local browser download settings. Search another folder adds a remembered root.
Automatic scans use five levels and a 3,500-folder budget per root; pick a deeper
folder manually if needed. Game assets, saves, runtime caches and links are skipped.
Game structure and three SHA-256 version markers identify the five reference builds.
ZIP contents are inspected, so renamed full-game ZIPs and renamed pack ZIPs work.
ZIP marker matches identify the version; they are not proof of every game's asset.
RAR/7z names suggest a target, then extracted contents/known archive hashes are
checked during installation. Unknown related archives remain unverified.
Corrupt ZIPs do not interrupt discovery. Detection alone never installs anything.

SAVES AND REVERSIBILITY
Save and close the game before switching or installing. Select any existing version
and press Switch & Play to return to its own game files and saves. No overwritten
game has to be downgraded. Launches back up saves; reconstructed profiles are checked
against their recorded file hashes. Saves supports backup, restore, and explicit
copying between versions with a destination backup. Copying does not convert saves.
Cross-version gameplay compatibility is unverified. In particular, 3.3.5 trial
removed the hypnosis storyline. Keep each version's original progress.

PORTABILITY AND STORAGE
Share Celesphonia-Delta-Launcher.zip plus the new any-version pack, or use original
game files instead. The clean launcher ZIP includes no game assets, personal saves,
local profile paths, or runtime caches. Extract it into a writable folder.
Native ZIP support needs no separate extractor. For split 7z/unsupported archives,
extract with a suitable archive program and select the extracted folder. Windows
tar provides RAR extraction where available; the local archive helper is not included
in the clean sharing ZIP. Each complete installed profile runs independently.
Install location changes where future profiles are created. Full profiles require
several GB each; the launcher checks available space before reconstruction.
See UPGRADE PATHS.md, TEST RESULTS.txt, and any-version-verification.json.
